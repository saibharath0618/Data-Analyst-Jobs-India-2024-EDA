# Data-Analyst-Jobs-India-2024-EDA
EDA of 1,561 Data Analyst job listings scraped from Naukri, Hirist &amp; IIMJobs (July 2024). Uncovered top cities (Bengaluru #1), in-demand skills (SQL, Python, Power BI), salary benchmarks (₹9.25L median) &amp; experience trends. Built with Python, Pandas &amp; Matplotlib.
